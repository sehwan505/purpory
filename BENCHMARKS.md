# Purpory Benchmarks

Purpory does not inherit or republish benchmark claims from its code-graph foundation.

The first public benchmark suite will measure:

- context CLI cold-start time without graph or LLM imports;
- SQLite latency with hundreds of topics and thousands of session deliveries;
- deterministic recall stability across Python platforms;
- pointer and graph-slice token reduction versus unscoped source delivery;
- dashboard API latency and static bundle size;
- cross-session answer quality with and without curated human context.

Until that harness and its raw results are committed, Purpory makes no comparative performance or
memory-accuracy claim.
